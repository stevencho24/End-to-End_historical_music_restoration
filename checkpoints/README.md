# Checkpoints

This directory is the stable local destination for released model weights; it
does not currently contain checkpoint binaries. Put the final paper model at:

```text
checkpoints/samecfm_40m_fos.pt
```

Large research checkpoints are normally hosted in a versioned archival
service (for example Zenodo or Hugging Face), not in ordinary Git history.
The release record should provide the exact paper/model version, license,
configuration, and SHA-256 checksum. The download URL and checksum for this
checkpoint will be added here when the weights are published.
